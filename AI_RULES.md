# AI Rules & Development Guidelines

This document outlines the core tech stack, library usage conventions, architecture boundaries, and legal-domain safety rules for **NyayaSetu (Bharat Legal Buddy)**. Any AI agent or developer modifying this repository must follow these rules.

---

## 1. Tech Stack Summary

- **Framework & SSR**: TanStack Start (`@tanstack/react-start`) with Vite 8 and React 19.
- **Routing**: TanStack Router (`@tanstack/react-router`) with file-based routing in `src/routes/` and route tree generation via `@tanstack/router-plugin`.
- **Language & Runtime**: TypeScript 5.8+ running on Node.js / Bun (compatible with Cloudflare / Nitro targets).
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`, OKLCH CSS variable design tokens) with `tw-animate-css`.
- **UI Components**: shadcn/ui primitives built on Radix UI, styled with Tailwind and `class-variance-authority`.
- **Icons**: Lucide React (`lucide-react`).
- **Markdown Rendering**: `react-markdown` + `remark-gfm` for rendering streaming AI legal responses and formatted advice.
- **Server API & AI Streaming**: Nitro/TanStack Start API route `/api/chat` (`src/lib/ai/legal-ai.server.ts`) streaming via native `fetch` and SSE/TextDecoder with Groq (primary) and OpenRouter (fallback).
- **State & Local Storage**: Browser `localStorage` managed via React Context (`SettingsProvider` in `src/lib/settings.tsx`) for user preferences, language, state selection, and saved Q&A.

## 2. Library Usage Matrix (What to Use for What)

| Purpose / Requirement | Allowed Library / Component | Strictly Disallowed / Deprecated |
|---|---|---|
| **Routing & Navigation** | TanStack Router (`<Link>`, `useNavigate()`, `createFileRoute()`, `search` params) | `react-router-dom`, `next/navigation`, window.location assignment |
| **Icons** | `lucide-react` | FontAwesome, react-icons, inline SVGs (unless custom national emblems) |
| **Notifications & Toasts** | Sonner (`sonner`, `<Toaster />`, `toast.success()`, `toast.error()`) | `react-toastify`, `react-hot-toast`, window.alert |
| **UI Component Primitives** | Radix UI primitives via `@/components/ui/*` (Dialog, DropdownMenu, Accordion, Select, Tabs, etc.) | Material-UI, Ant Design, Bootstrap, unstyled raw modal divs |
| **Class Merging** | `cn()` helper (`clsx` + `tailwind-merge` in `@/lib/utils.ts`) | Manual string concatenation, raw template strings with conflicting classes |
| **Markdown / Legal Output** | `react-markdown` with `remark-gfm` wrapped in `.prose-legal` class | `dangerouslySetInnerHTML`, markdown-it |
| **Server AI Streaming** | Fetch streaming via `src/lib/stream-chat.ts` calling `/api/chat` | Client-side SDK calls exposing `GROQ_API_KEY` or `OPENROUTER_API_KEY` to browser |
| **Forms & Inputs** | `react-hook-form` + `zod` for complex forms; standard controlled React state for quick search bars | Uncontrolled inputs without state synchronization |
| **Data Fetching / Cache** | `@tanstack/react-query` for asynchronous server queries; static imports for curated laws | `axios`, manual unhandled fetch promises |

## 3. Architectural Rules & Conventions

1. **File-Based Routing Only**:
   - Every view route resides in `src/routes/<path>.tsx`.
   - Never create `src/pages/`, `src/routes/_app/`, or Next.js `app/` folders.
   - Do not edit `src/routeTree.gen.ts` manually; it is auto-generated by TanStack Router.
   - Keep root-level providers and layouts in `src/routes/__root.tsx`.

2. **Source of Truth for Legal Data**:
   - Reference data lives in `src/data/legal.ts` and `src/data/templates.ts`.
   - The offline knowledge base JSON (`src/data/kb/*.json`) is generated by running `bun scripts/build-kb.ts`.
   - **Never edit JSON files in `src/data/kb/` directly.** Edit `src/data/legal.ts` and re-run the build script.

3. **API Keys & AI Execution**:
   - Provider keys (`GROQ_API_KEY`, `OPENROUTER_API_KEY`) must remain server-side.
   - The server route `/api/chat` handles streaming and fallbacks before dispatching chunks to the client.
   - User-supplied keys (if configured) are handled through request headers/body via server proxy, never exposed to external clients.

4. **Component Design**:
   - Keep components modular, responsive, and under 100-150 lines where possible.
   - Place reusable UI building blocks in `src/components/ui/` and app-specific feature components in `src/components/app/`.

## 4. Legal Compliance & AI Safety Rules

- **Not a Lawyer**: All AI responses and generated templates must include explicit disclaimers:
  > *"NyayaSetu provides general legal information, not legal advice. Consult a licensed advocate before acting."*
- **Criminal & Custodial Detection**: Use the `HIGH_RISK` regex pattern (`src/lib/settings.tsx`) across search and input fields to surface high-priority emergency alerts:
  - Police Emergency: `112`
  - Cyber Crime Helpline: `1930`
  - Women Helpline: `1091` / `181`
  - Free Legal Aid: `NALSA 15100`
- **Zero Hallucination Policy**:
  - Never fabricate section numbers, Article numbers, or court citations.
  - Rely on current criminal laws (BNS 2023, BNSS 2023, BSA 2023) effective from 1 July 2024. Reference repealed acts (IPC, CrPC, IEA) only for transitional context.
  - Mark unverified fields as `DATA_NOT_AVAILABLE` rather than guessing.
